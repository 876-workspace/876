# @876/docs

A minimal, standard, templated Astro site for 876 documentation. It ships with
an empty home page and a shared base layout, ready to grow into the docs site.

Run it with `pnpm --filter @876/docs dev` — the dev server serves on port **3008**.
Build with `pnpm --filter @876/docs build` and preview with
`pnpm --filter @876/docs preview` (also port 3008).
