# GPT web delegation reports

Reports written by ChatGPT web (GPT‑5.6) after executing a brief from
`.claude/briefs/gpt-web/`. One report per brief, named identically to the brief
it answers.

GPT web cannot run commands, migrations, or database queries in this repo. Its
report is therefore a **claim about files written**, never evidence that anything
works. The orchestrating agent owns every verification listed in the brief's
"Verification" section, and reads the report's "Decisions", "Could not verify",
and "Risk notes" sections before accepting the work.

A report that claims a command was run or a test passed is wrong on its face and
the work behind it should be re-reviewed line by line.
